Dergi Takibi

Cihazlar arasında eşitleme

Kaydettikleriniz ve okundu işaretleri GitHub deponuzda tutulur; telefon ve bilgisayar aynı listeyi görür. Bu cihaz için bir kez erişim anahtarı girmeniz yeterli.

  1. GitHub'da yeni anahtar sayfasını açın.
  2. Ad: dergi-takip, süre: en uzun seçenek.
  3. Repository access: Only select repositories, ardından dergi-takip.
  4. Repository permissions: Contents: Read and write.
  5. Generate token deyin ve anahtarı aşağıya yapıştırın.

Anahtar yalnızca bu tarayıcıda saklanır ve sadece GitHub'a gönderilir.
