Dergi Takibi

Kaydedilenleri cihazlar arasında eşitle

Kaydettiğiniz makaleler GitHub deponuzdaki data/saved.json dosyasına yazılır. Bu cihazdan kaydedebilmek için bir kez erişim anahtarı girmeniz gerekir.

  1. GitHub'da yeni anahtar oluşturma sayfasını açın.
  2. Ad: dergi-takip, süre: en uzun seçenek.
  3. Repository access: Only select repositories → dergi-takip.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token deyin, çıkan anahtarı kopyalayıp aşağıya yapıştırın.

Anahtar yalnızca bu tarayıcıda saklanır ve sadece GitHub'a gönderilir. Telefonda da bir kez aynı anahtarı girmeniz yeterli.
